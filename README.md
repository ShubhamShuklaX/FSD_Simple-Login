

# 🔐 Simple Login System

A minimal login system using **HTML/CSS/JS frontend** and **Node.js (Express)** backend with hardcoded credentials.

---

## 📌 Features

* Modern UI
* Login validation (`admin / 1234`)
* Frontend → Backend POST API
* Error handling

---

## 🚀 How to Run

### **Backend**

```sh
cd backend
npm install express cors
node server.js
```

### **Frontend**

Just open:

```
index.html
```

---

## 📂 API Route

| Method | Route  | Description           |
| ------ | ------ | --------------------- |
| POST   | /login | Validates credentials |

---

## ✔️ Default Credentials

* **Username:** admin
* **Password:** 1234
